# Release

Материалы для публикации в Chrome Web Store. В расширение ничего отсюда не попадает.

| Папка | Что внутри |
| --- | --- |
| `promo/` | Промо-плитки CWS. Правим `*.src.html`, коммитим `.png`; собранный `.html` со встроенными шрифтом и картинками — артефакт, он в `.gitignore`. |
| `screenshots/<локаль>/` | Скриншоты карточки, 1280×800, по папке на язык. |
| `img/` | Исходники графики для плиток: `logo.png` — пешка 1254×1254 с прозрачным фоном. |
| `figma/` | SVG со слоями для правки в Figma. Пересобирается, в git не хранится. |
| `listing/<локаль>/` | `description.txt` — подробное описание карточки, готовое к вставке. |
| `chess-cheating-signals-<version>.zip` | Архив расширения для загрузки. |

## Сборка

```sh
node release/promo/build.mjs     # перерисовать все промо-плитки из *.src.html
node release/promo/build.mjs v3  # только варианты, в имени которых есть "v3"
node release/promo/build.mjs screenshot   # скриншот на все локали
node release/promo/to-svg.mjs    # выгрузить собранные макеты в SVG со слоями (release/figma)
node release/pack.mjs            # собрать zip: manifest.json, _locales, src, icons, svg, fonts, i18n
```

`pack.mjs` кладёт в архив только рабочие файлы: из `svg/` уезжают пять бейджей и индикатор,
исходники из Figma остаются в репозитории. Архив пишется pwsh 7+ или bsdtar — Windows
PowerShell 5.1 ставит в путях `\`, и стор такой zip разбирает неверно.

`build.mjs` берёт размер из имени файла (`promo-tile-440x280.src.html` → 440×280),
подставляет вместо `{{FONT_LATIN}}`, `{{FONT_CYRILLIC}}`, `{{LOGO}}` (иконка 256px),
`{{LOGO_BIG}}` (`img/logo.png`) и `{{BOARD}}` встроенные data-URL
и снимает PNG headless-Chrome'ом. `{{FILE:_tile.css}}` подставляет партиал из этой же папки.
Чтобы добавить формат (marquee 1400×560, скриншот 1280×800) — копируем исходник
под новым именем с нужным размером; файлы на `_` как страницы не собираются.

## Варианты плитки 440×280

Вёрстка у всех общая — `_tile.css` и `_tile.html`. Вариант задаёт только фон и четыре
переменные цвета (`--fg`, `--fg-2`, `--accent`, тени), поэтому текст правится один раз
для всех сразу.

| Файл | Фон |
| --- | --- |
| `v1-board` | Тёмная доска `#312e2b`, клетки, зелёный свет слева — как в герое лендинга. |
| `v2-night` | Почти чёрный `#161513`, одно пятно света за фигурой, виньетка. Самый контрастный. |
| `v3-wood` | Настоящая доска (`docs/assets/board.png`) под затемнением, к тексту уходит в темноту. |
| `v4-warm` | Светлое дерево, тёплый градиент, тёмный текст. |
| `v5-green` | Зелёный градиент chess.com: фигура на тёмной части, текст на зелёной. |
| `v6-light` | Белый фон лендинга с зелёной подсветкой и тонкой сеткой клеток. |

Выбранный вариант загружаем в стор как есть — переименовывать не нужно.

## Обложки 1400×560 (marquee)

В стиле лендинга: белый фон, тёмный заголовок с зелёным акцентом, справа — карточка
соперника с доской, внизу слева — «works right inside chess.com». Разметка общая
(`_hero.html` + `_hero.css`), вариант меняет фон и подачу.

| Файл | Чем отличается |
| --- | --- |
| `v1-hero` | Белый фон с зелёным свечением, как `.hero::before` на лендинге. Карточка ровно, без фигуры. |
| `v2-hero-soft` | Мягкий серо-зелёный градиент с сеткой клеток, карточка под наклоном, пешка стоит перед ней. |

Крупная фигура по умолчанию скрыта (`.pawn { display: none }`) — вариант включает её сам.

## Локализация

Локали: **en, ru, uk, hi, id, de, es, fr, pt_BR** — коды как в `_locales/`.

Тексты карточки лежат в `listing/<локаль>/description.txt` — простым текстом, без разметки:
поле в магазине markdown не понимает. Макет локализуется на сборке:
исходник с пометкой `<!-- l10n -->` собирается по разу на каждую локаль из `promo/strings.json`.

Строки в макете двух видов:

| Токен | Откуда берётся |
| --- | --- |
| `{{T:headline1}}` | `promo/strings.json` — маркетинговый текст, пишется руками под ширину колонки |
| `{{I18N:badgeLucky\|70}}` | `i18n/<код>.json` — те же переводы, что пользователь видит в расширении |

Второе важнее первого: подсказка на скриншоте показывает ровно тот текст, который человек
увидит у себя, и при правке переводов расширения скриншоты обновятся сами.

Новый язык: добавить блок в `promo/strings.json` (нужен и файл `i18n/<код>.json`),
завести `listing/<код>/listing.md`, пересобрать. Заголовок держать в пределах ~17 знаков
на строку — иначе он поедет на третью строку и собьёт отступы.

Локализуются только описание, скриншоты и видео — по вкладке языка в дашборде.
Промо-плитка 440×280 и обложка 1400×560 общие для всех языков, переводить их магазин не даст.

### Знак поддержки Украины

В шапке скриншота справа — иконка из `img/icon green - support ukraine.svg` (вшита в разметку
вектором, белая подложка убрана) и подпись из ключа `support` в `strings.json`.
На русской локали знака нет: на `.cover` проставляется `data-locale`, правило
`.cover[data-locale="ru"] .support { display: none }` в `_shot.css` его скрывает,
и подпись для `ru` в `strings.json` пустая — то есть блокировка двойная.
На плитках и обложках знака нет: разметка общая, но показывают его только стили скриншота.

У Inter нет деванагари, поэтому для `hi` подключён запасной шрифт (`Nirmala UI`,
`Noto Sans Devanagari`) — на машине без них хинди-скриншот отрисуется другим шрифтом.

## Правка в Figma

`to-svg.mjs` открывает собранную страницу в headless-Chrome, снимает фон отдельной
картинкой, обмеряет каждый элемент (позицию, шрифт, базовую линию, цвет) и складывает
из этого SVG. В Figma он импортируется слоями с понятными именами: `headline`, `lead`,
`lockup`, `board`, `LUCKY`, `pawn` и так далее.

Что переносится: текст — настоящим текстом на Inter (шрифт есть в Figma из коробки,
плюс он вшит в файл, чтобы SVG правильно выглядел и в браузере); бейджи и индикатор —
вектором; доска, логотип и пешка — картинками; поворот карточки — группой с углом.

Что не переносится: фон с градиентами и клетками лежит нижним слоем-картинкой
(`background`), тени у карточки и бейджей не экспортируются — в Figma их добавляют эффектом.
Перенос строки SVG не умеет, поэтому каждая строка абзаца — отдельный текстовый слой.

Альтернатива, если нужна полная структура с автолейаутом: плагин html.to.design в Figma —
ему скармливают собранный `*.html` из `promo/`.

## Форматы CWS

| Ассет | Размер | Статус |
| --- | --- | --- |
| Иконка стора | 128×128 | `icons/icon-128.png` |
| Small promo tile | 440×280 | `promo/promo-tile-440x280-*.png`, 6 вариантов |
| Marquee promo tile | 1400×560 | `promo/marquee-1400x560-*.png`, 2 варианта |
| Скриншоты | 1280×800 | минимум 1, лучше 4–5 |

PNG без альфа-канала, без скруглений и рамок — стор рисует их сам.

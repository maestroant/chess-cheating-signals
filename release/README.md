# Release

Материалы для публикации в Chrome Web Store. В расширение ничего отсюда не попадает.

| Папка | Что внутри |
| --- | --- |
| `promo/` | Промо-плитки CWS. Правим `*.src.html`, коммитим `.png`; собранный `.html` со встроенными шрифтом и картинками — артефакт, он в `.gitignore`. |
| `screenshots/` | Скриншоты для карточки стора: 1280×800 или 640×400, PNG, до 5 штук. |
| `img/` | Исходники графики для плиток: `logo.png` — пешка 1254×1254 с прозрачным фоном. |
| `listing/` | Тексты карточки: название, краткое и полное описание по локалям. |
| `chess-cheating-signals-<version>.zip` | Архив расширения для загрузки. |

## Сборка

```sh
node release/promo/build.mjs     # перерисовать все промо-плитки из *.src.html
node release/promo/build.mjs v3  # только варианты, в имени которых есть "v3"
node release/pack.mjs            # собрать zip: manifest.json, _locales, src, icons, svg, fonts, i18n
```

`pack.mjs` кладёт в архив только рабочие файлы: из `svg/` уезжают пять бейджей и индикатор,
исходники из Figma остаются в репозитории. Архив пишется pwsh 7+ или bsdtar — Windows
PowerShell 5.1 ставит в путях `\`, и стор такой zip разбирает неверно.

`build.mjs` берёт размер из имени файла (`promo-tile-440x280.src.html` → 440×280),
подставляет вместо `{{FONT_LATIN}}`, `{{FONT_CYRILLIC}}`, `{{LOGO}}` (иконка 256px),
`{{LOGO_BIG}}` (`img/logo.png`) и `{{BOARD}}` встроенные data-URL
и снимает PNG headless-Chrome'ом. `{{FILE:_tile.css}}` подставляет партиал из этой же папки.
Чтобы добавить формат (marquee 1400×560, скриншот 1280×800) — копируем исходник
под новым именем с нужным размером; файлы на `_` как страницы не собираются.

## Варианты плитки 440×280

Вёрстка у всех общая — `_tile.css` и `_tile.html`. Вариант задаёт только фон и четыре
переменные цвета (`--fg`, `--fg-2`, `--accent`, тени), поэтому текст правится один раз
для всех сразу.

| Файл | Фон |
| --- | --- |
| `v1-board` | Тёмная доска `#312e2b`, клетки, зелёный свет слева — как в герое лендинга. |
| `v2-night` | Почти чёрный `#161513`, одно пятно света за фигурой, виньетка. Самый контрастный. |
| `v3-wood` | Настоящая доска (`docs/assets/board.png`) под затемнением, к тексту уходит в темноту. |
| `v4-warm` | Светлое дерево, тёплый градиент, тёмный текст. |
| `v5-green` | Зелёный градиент chess.com: фигура на тёмной части, текст на зелёной. |
| `v6-light` | Белый фон лендинга с зелёной подсветкой и тонкой сеткой клеток. |

Выбранный вариант загружаем в стор как есть — переименовывать не нужно.

## Обложки 1400×560 (marquee)

В стиле лендинга: белый фон, тёмный заголовок с зелёным акцентом, справа — карточка
соперника с доской, внизу слева — «works right inside chess.com». Разметка общая
(`_hero.html` + `_hero.css`), вариант меняет фон и подачу.

| Файл | Чем отличается |
| --- | --- |
| `v1-hero` | Белый фон с зелёным свечением, как `.hero::before` на лендинге. Карточка ровно, без фигуры. |
| `v2-hero-soft` | Мягкий серо-зелёный градиент с сеткой клеток, карточка под наклоном, пешка стоит перед ней. |

Крупная фигура по умолчанию скрыта (`.pawn { display: none }`) — вариант включает её сам.

## Форматы CWS

| Ассет | Размер | Статус |
| --- | --- | --- |
| Иконка стора | 128×128 | `icons/icon-128.png` |
| Small promo tile | 440×280 | `promo/promo-tile-440x280-*.png`, 6 вариантов |
| Marquee promo tile | 1400×560 | `promo/marquee-1400x560-*.png`, 2 варианта |
| Скриншоты | 1280×800 | минимум 1, лучше 4–5 |

PNG без альфа-канала, без скруглений и рамок — стор рисует их сам.

Тексты карточки Chrome Web Store, по папке на локаль — коды те же, что в `_locales/`,
дашборд берёт список языков именно из этих папок расширения.

```
<локаль>/description.txt   подробное описание — вставляется в дашборде как есть
<локаль>/README.md         что в этой локали куда идёт
```

## Как поле устроено в магазине

Подробное описание — простое текстовое поле, до 16 000 символов. Markdown и HTML там
не работают: `**жирный**` и `## заголовок` показались бы как есть. Поэтому в
`description.txt` разметки нет — только переносы строк (их магазин сохраняет),
заголовки разделов капсом и маркеры списка символом «•».
Копировать файл целиком, ничего не дописывая.

## Что откуда берётся

| Поле | Источник |
| --- | --- |
| Name, Summary | манифест, то есть `_locales/<локаль>/messages.json` — в дашборде не правятся |
| Description | `<локаль>/description.txt`, вставляется руками на вкладке языка |
| Screenshots | `release/screenshots/<локаль>/`, загружаются на вкладке языка |
| Промо-плитка 440×280 и обложка 1400×560 | **не локализуются** — одна пара на все языки |

Готовы: en, ru, uk, hi, id, de, es, fr, pt_BR. В дашборде `pt_BR` называется `pt-BR`.
